# Modulos

Los modulos representan capacidades reutilizables que pueden ser usadas por productos finales sin convertir Foundation en un dominio de negocio.

## Criterios para aceptar un modulo

- Tiene una responsabilidad clara.
- Puede describirse sin vocabulario de un producto especifico.
- Expone contratos o puntos de extension estables.
- Declara sus dependencias.
- Puede probarse de forma aislada.

## Candidatos conceptuales

- Auth
- Users
- Roles and Permissions
- Tenancy
- Settings
- Branding
- Notifications
- Media
- Audit
- Search
- Payments

Estos candidatos no implican implementacion inmediata.
