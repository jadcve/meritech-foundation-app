# Reglas del Proyecto

- Usar `codebase-memory-mcp` antes de analizar estructura o relaciones.
- Confirmar que el cambio respeta las ADR.

- No ampliar Core sin justificacion arquitectonica.
- No crear modulos por anticipacion.
- Mantener la documentacion sincronizada con las decisiones.
