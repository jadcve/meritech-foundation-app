# Contribucion

## Antes de cambiar

1. Consultar `codebase-memory-mcp`.
2. Revisar ADR vigentes.
3. Identificar la capa afectada.
4. Confirmar que Foundation sigue siendo agnostico del negocio.
5. Documentar la decision si se crea una estructura nueva.

## Durante el cambio

- Mantener el alcance minimo.
- No mezclar documentacion, arquitectura y funcionalidad en un mismo cambio salvo que este justificado.
- Agregar pruebas cuando exista comportamiento nuevo.

## Para esta fase

Esta fase es exclusivamente documental. No se implementan funcionalidades.
