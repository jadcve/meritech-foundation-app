# Estandares de Codigo

## Principios

- Respetar convenciones de Laravel salvo ADR contraria.
- Mantener Core pequeno y estable.
- Evitar dependencias de negocio en Foundation.
- Preferir contratos claros a acoplamientos implicitos.
- Documentar decisiones estructurales.

## Reutilizacion

Antes de crear una clase, servicio, modulo o convencion nueva, revisar si existe una pieza equivalente. Si se decide crear, documentar por que la reutilizacion no era suficiente.
