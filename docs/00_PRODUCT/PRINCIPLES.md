# Principios

## Agnostico del negocio

Foundation no contiene reglas, nombres ni flujos de un negocio especifico.

## Core primero

Las capacidades centrales deben ser pequenas, estables y justificadas.

## Documentar antes de expandir

Toda decision estructural debe quedar registrada antes de introducir cambios de alto impacto.

## Modularidad con criterio

Un modulo existe solo si aporta una capacidad reutilizable con limites claros.

## Reutilizar antes de crear

Cuando una convencion existente resuelve el problema, se reutiliza. Si se crea algo nuevo, se documenta la razon.
