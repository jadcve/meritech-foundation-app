# Mision

Meritech Foundation existe para reducir la friccion de crear productos SaaS consistentes.

Su mision es entregar una base documentada, extensible y agnostica del negocio, donde las decisiones tecnicas centrales esten claras antes de implementar capacidades de producto.

Foundation debe ayudar a los equipos a:

- iniciar productos con una arquitectura comun;
- evitar repetir decisiones base;
- separar plataforma de negocio;
- documentar criterios antes de codificar;
- crecer sin convertir el Core en un producto especifico.
