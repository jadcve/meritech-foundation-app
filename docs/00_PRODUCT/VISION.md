# Vision de Meritech Foundation

## Por que existe Foundation

Foundation existe para darle a Meritech una base tecnologica comun para construir productos SaaS reutilizables. Su objetivo es evitar que cada producto nazca como una solucion aislada, con decisiones repetidas, estructuras incompatibles y logica dificil de reutilizar.

Foundation nace para ordenar antes de construir. Antes de crear autenticacion, tenancy, permisos, pagos o dashboards, Meritech necesita una arquitectura compartida que defina limites, responsabilidades y criterios de crecimiento.

## Problemas que resuelve

Foundation resuelve problemas estructurales, no problemas de un unico producto.

- Repeticion de decisiones tecnicas entre proyectos.
- Mezcla de logica de producto con logica reutilizable.
- Dificultad para extraer capacidades comunes.
- Falta de reglas para crear modulos.
- Crecimiento desordenado de aplicaciones SaaS.
- Dependencia excesiva de nombres, modelos o necesidades de un producto puntual.
- Ambiguedad entre base tecnologica y producto final.

## Productos que podra construir

Foundation podra servir como base para distintos productos SaaS de Meritech, incluyendo:

- plataformas B2B;
- paneles administrativos;
- productos multiusuario;
- productos con roles y permisos;
- soluciones multiempresa o multicliente;
- sistemas con configuraciones por tenant, marca o producto;
- herramientas con notificaciones, medios, auditoria y busqueda;
- productos con integraciones de pagos o comunicaciones;
- nuevas lineas de negocio digitales de Meritech.

Foundation no define el mercado final. Define la base para que distintos productos puedan existir con una arquitectura comun.

## Que nunca sera Foundation

Foundation nunca sera:

- Nexura;
- Restaurant;
- Menu;
- CRM;
- ERP;
- un producto final empaquetado para un unico mercado;
- una copia de una aplicacion existente;
- un framework independiente que compita con Laravel;
- un contenedor de funcionalidades sin limites claros;
- un lugar para resolver necesidades urgentes de un producto especifico sin criterio reutilizable.

Foundation debe mantenerse como base tecnologica. Los productos finales deben construirse sobre ella, no dentro de ella.
