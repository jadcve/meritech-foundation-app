# Alcance de Producto

## Dentro del alcance

- Definir vision, mision y principios.
- Establecer reglas arquitectonicas.
- Documentar decisiones mediante ADR.
- Mapear la estructura tecnica actual.
- Preparar criterios para futuros modulos reutilizables.
- Mantener una base Laravel limpia y extensible.

## Fuera del alcance

- Implementar funcionalidades de negocio.
- Crear dominios de producto.
- Agregar modelos, controladores, servicios o migraciones sin decision previa.
- Instalar paquetes sin ADR y justificacion.
- Convertir Foundation en una aplicacion final.
